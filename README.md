# Déjà Vous — Android downloads

Public APK releases for Déjà Vous. Application source code stays in a separate private repository.

Download the APK from [Releases](https://github.com/tybiboune/DejaVous-apk/releases). Updater-enabled Android builds check for new releases and download verified APKs. Android asks you to approve installation.

Each release contains `deja-vous.apk` and `update.json`. Update checks send no game answers or vault content. Only APKs signed with the app's persistent signing key can update an installed release build.

Version 1.0.1 fixes the startup logo freeze: [Download the latest version](https://github.com/tybiboune/DejaVous-apk/releases/latest). Install it over 1.0.0 without uninstalling. Android asks for installation approval. An earlier debug APK may have a different signing key; do not uninstall it if you need its saved data.
