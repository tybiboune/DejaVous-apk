Où coller votre code ? En 5 gestes

Faites défiler les étapes →

  1. 1

    Installez l’appli

    Pas encore installée ? Téléchargez l’APK sur ce téléphone, ouvrez le fichier et acceptez l’installation. Déjà installée ? Passez à l’étape 2.

    Télécharger l’APK
  2. 2

    Ouvrez les réglages

    Sur l’écran d’accueil de Déjà Nous, touchez la petite roue crantée, en haut à droite.

  3. 3

    Touchez « Débloquer le jeu complet »

    Descendez jusqu’au bloc « Code, sauvegarde & édition complète », puis touchez le bouton rose.

  4. 4

    Collez le code

    Sous « Vous avez déjà un code ? », touchez le champ « Code de déverrouillage », collez le code (appui long, puis Coller), puis touchez « Valider le code ».

  5. 5

    C’est débloqué !

    Les réglages affichent « Version complète activée ». Toutes les cartes sont à vous, sur ce téléphone et, avec le même code, sur celui de l’autre.
